# VIZIT brand assets

- `vizit-logo-master.png`: a felhasználó által jóváhagyott, változatlan forrásfájl.
- `vizit_logo_full.png`: az alkalmazásban használható, körbevágott teljes logó.
- `vizit_logo_mark.png`: a „V + NFC” márkajel, felirat nélkül.
- `ic_launcher_foreground_logo.png`: az adaptív Android alkalmazásikon biztonságos zónájára méretezett márkajel.

A származtatott Android-fájlok az `app/src/main/res/drawable-nodpi` mappában találhatók. A logót generatív módon nem szabad újrarajzolni vagy a képarányát torzítani.
